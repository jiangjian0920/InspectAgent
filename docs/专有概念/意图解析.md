# 意图解析

入口：`agent.intent.parse_intent(instruction, default_time_range)`。

输出 `InspectionIntent`：`user_input`、`time_range`、`cluster_wide`、`targets`。

每个 target：`target_type`、`skill`、`instance`、`metrics`。

## 路由规则

- 命中全集群关键词（含「全面巡检」「全集群巡检」等）-> 四个 target 全出
- 否则按 redis / kafka / k8s / server 关键字收窄
- 只出现 IP、没有任何组件词 -> 默认 server
- 完全没有对象线索 -> 仍默认 server

点名 CPU/磁盘等只填对应 `metrics`；未点名且是巡检语义时 `metrics=[]`，Skill 走基础健康集。
